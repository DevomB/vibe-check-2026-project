# __PKG__

One sentence: what this software does and the headline property we proved.

## What is proved

Generated by `audit.py --report` into `VERIFICATION.md`. Each property in
`__LIB__/Spec.lean` is listed with its English meaning, the theorem that proves
it, and the axioms that proof rests on.

## What is not proved

Be explicit. Typical entries:

- I/O, the UI and everything in `Main.lean`.
- For ports of existing code: that the port behaves like the original. We
  differential-tested it on N random inputs (command: `...`).
- The Lean compiler and runtime.

## Run it

```bash
lake build
lake exe __PKG__
```

## Check the proofs yourself

```bash
lake build                       # must finish with no 'sorry' warnings
python3 .vibecheck/tools/audit.py
```
